# Azalea Kamellia Abdullah, Gs.

I am a geospatial data scientist and MPhil researcher specializing in remote sensing, machine learning, and hydroclimatology. I build automated geospatial pipelines and drought monitoring tools, bridging the gap between rigorous academic research and practical environmental consulting.

Currently, I am completing my MPhil in Remote Sensing at Universiti Teknologi Malaysia (UTM), collaborating with the Sarawak State Government on satellite precipitation bias correction for data-scarce tropical regions.

---

## 🛠️ Tools & Libraries

I develop both open-source utilities for the scientific community and enterprise-grade tools for corporate ESG/TCFD reporting, guided by a dual-license framework.

| Project | Description |
| :--- | :--- |
| **[STEMRAINCAL](https://github.com/azaleakamellia)** | A registered (MyIPO) Python library for computing standardised drought indices from hydrometeorological inputs. |
| **TCFD Drought Risk Pipeline** | *(In Development)* An automated workflow ingesting CHIRPS/ERA5/CMIP6 data to output standardized SPI metrics for corporate climate risk reporting. |
| **ESIA Geospatial Checklist** | *(Coming Soon)* A curated, open-source reference for acquiring and validating spatial data for Malaysian environmental assessments. |
